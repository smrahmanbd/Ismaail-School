# Ismaail-School

Study materials, organised by subject and grade.

| Folder | What's inside |
|--------|---------------|
| [Grade 10 Chemistry](Grade%2010%20Chemistry/) | **The Mole** (Module 9): 8 interactive animated lessons, endless practice problems, step-by-step notebook solutions, and a printable study guide (PDF) |

## Open the lessons
- **Download:** green **Code** button → *Download ZIP* → unzip → open `Grade 10 Chemistry/index.html` in any browser.
- **As a website:** Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save. After a minute the lessons are at
  `https://smrahmanbd.github.io/Ismaail-School/Grade%2010%20Chemistry/`
